## 🌱 Projeto em destaque

### 💜 Meu Ritmo

**Meu Ritmo** é um projeto autoral desenvolvido com **HTML, CSS e JavaScript**, criado para explorar uma experiência mais simples, acessível e confortável de organização de tarefas.

A proposta é reduzir a sobrecarga e valorizar **clareza, autonomia e acessibilidade**, permitindo que cada pessoa organize suas tarefas de acordo com o seu próprio ritmo.
